# MagisGate

MagisGate is a modern Android application for managing root-level operations and logs, built with Jetpack Compose.

## Features
- View and filter system logs.
- Manage application information.
- Filter and sort applications.
- Material 3 Design.

## Screenshots
*Screenshots will be available in the `fastlane/metadata/android` directory.*

## Build from Source
To build the app yourself, ensure you have Android SDK installed and run:
```bash
./gradlew assembleRelease
```
The signed APK will be available in `app/build/outputs/apk/release/app-release.apk`.
